# Neural Network Fundamentals and Training Behavior Analysis

## Objective
The objective of this project is to build and analyze a feed-forward neural network for customer churn prediction.

## Data Set Used - Customer_Churn_nn.csv

## Tasks Performed
- Dataset understanding
- Data preprocessing
- Neural network model building
- Model training and evaluation
- Hyperparameter experimentation
- Final analysis and reflection

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow/Keras

## Model Overview
A feed-forward neural network was implemented using TensorFlow/Keras. The model was trained on a customer churn dataset after preprocessing and feature scaling.

## Evaluation Metrics
- Accuracy
- Loss
- Confusion Matrix
- Classification Report

## Hyperparameter Experiments
Multiple experiments were conducted by changing:
- Number of neurons
- Activation functions
- Number of epochs

## Conclusion
The neural network successfully learned customer churn prediction patterns. Hyperparameter tuning demonstrated how architecture and training configuration affect model performance.
